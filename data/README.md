# PortfolioIQ
## Personalised Portfolio Risk Intelligence Dashboard

PortfolioIQ is a Python-based financial analytics application
that helps individual investors understand portfolio performance,
risk exposure and diversification.

### Problem
Individual investors may not understand how much risk their
stock portfolios carry or how concentrated their holdings are.

### Solution
PortfolioIQ analyses user-selected stock holdings and investment
amounts, then provides personalised portfolio metrics and
risk observations.

### Features
- Personalised investor profile
- Stock selection and investment allocation
- Historical portfolio performance
- Nifty 50 benchmark comparison
- Annualised return and volatility
- Portfolio beta
- Maximum drawdown
- Sharpe and Sortino ratios
- Stock correlation heatmap
- Historical Value at Risk
- Market stress simulation
- Downloadable portfolio reports

### Technology
Python, Streamlit, Pandas, NumPy and Plotly.

### Data
Historical adjusted closing prices downloaded using yfinance
from Yahoo Finance.

### Disclaimer
This is an educational analytics project and does not provide
investment advice or guarantee future returns.
